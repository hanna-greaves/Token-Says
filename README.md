# Token Says — Deprecated

**This module is no longer maintained.** It has been succeeded by [Token Quips](https://github.com/themrbeasley/Token-Quips), which carries forward the full feature set with Foundry V13+ compatibility, bug fixes, and new capabilities.

Please use **Token Quips** for all new installations and updates:

**[https://github.com/themrbeasley/Token-Quips](https://github.com/themrbeasley/Token-Quips)**

---

## Migrating

Token Quips is a direct continuation of Token Says. Your existing sayings and configuration will carry over. Install Token Quips from the new repository and remove Token Says.
